Plataforma web para la gestión y reserva de servicios.

## Tecnologías

- **Backend:** Java y Spring Boot
- **Frontend:** React
- **Base de datos:** PostgreSQL
  
## Objetivos

Desarrollar una aplicación web que permita a los clientes consultar servicios, reservar horarios disponibles y gestionar sus reservaciones, mientras el administrador configura los horarios, administra los servicios y supervisa las citas.

## Estado del proyecto

En fase inicial de configuración y desarrollo.
